  2. 02

求人票で最初に見るところ4選

次に、求人を見るときの道具です。これだけ知っていれば、だいぶ避けられます。

  1. 「年間休日120日以上」の「以上」を見る

    「以上」と書いてあるとき、保証されているのは下限の120日だけです。実際は120日ちょうどだと思って見てください。120日はだいたい土日祝が休みの計算で、110日なら月1回は土曜出勤がある計算になります。

  2. 「みなし残業」は、何時間分かを見る

    固定残業代・みなし残業と書いてある場合、何時間分が含まれているかは本来明示される項目です。そこが長いと、その時間までは働く前提の設計。書いていない求人票があったら、そこを聞くだけで一段わかります。

  3. 「アットホームな職場」は情報ではない

    書いてあっても減点にはしません。ただ、給与・休日・残業のどれかが書かれていない求人票ほど、この言葉が入りやすい。この言葉を見つけたら、代わりに書かれていない欄を探してください。

  4. 離職率は、求人票の外で調べられる

    求人票に載っていなくても、会社の採用ページや口コミで人の入れ替わりの速さは見えてきます。どこを見るか、それさえ覚えておけば自分で確かめられる。

よくある質問

Q 今の会社にバレませんか？
A ご本人の同意なく、今の会社へ連絡することはありません。在職中であることは提携先にも共有したうえで進めます。こちらからの連絡はLINEのみです。
Q まだ辞めると決めていなくても大丈夫ですか？
A 決まっていない状態で聞きに来ていただいてかまいません。聞くだけで終わった場合も、こちらから催促はしません。
Q 相談だけでもいいですか？
A はい。求人を見ずに終わっても問題ありません。
Q 応募していない求人でもいいですか？
A むしろ応募前のほうが、選び直せます。
Q 他社のエージェント経由の求人でもいいですか？
A 見るだけなら問題ありません。応募の進め方は、そのエージェントの流れを優先してください。
Q 見てもらったら、応募しなきゃダメですか？
A 不要です。見たうえで応募しない、という結論でかまいません。
Q スクショでもいいですか？
A スクショでもURLでも、会社名だけでも見られます。
Q 何件まで見てもらえますか？
A いまのところ上限は設けていません。1件でも、3件並べてでも大丈夫です。
Q しつこく連絡が来ませんか？
A 個別の電話や催促はしません。お知らせの配信は自動で届きます。止めたいときは「停止」と送ってください。
Q 本当に無料ですか？
A 無料です。採用が決まったときに、企業側から紹介手数料をいただく仕組みです。
Q 電話がかかってきますか？
A やり取りはLINEの文字から始めます。電話で話したい方は、つながりやすい時間帯を教えてください。
Q 何を準備すればいいですか？
A 何もいりません。職務経歴書は、書いたものを提携先の担当者が見て直します。まだ無ければ、その場で一から作るところから始められます。
Q 話が進むと、顔を出して話すことになりますか？
A ご希望があればビデオ通話もできますが、必須ではありません。部屋着でもスッピンでも平気ですし、カメラを切ったまま声だけでもできます。文字のやり取りだけで終えていただいても差し支えありません。
Q 高卒・フリーターでも対象ですか？
A どちらも対象に含みます。経歴を先に整えてから来る必要はありません。
Q 送るときに個人情報はいりますか？
A 求人票を見るだけなら不要です。お仕事のご紹介に進みたいときに、送り先をうかがいます。
Q 入力した情報はどこへ行きますか？
A 提携先や求人企業へのご紹介に進むときは、提供先と提供する項目をお示しし、ご同意をいただいてからにします。ご同意がなければ提供しません。なお、やり取りの性質上、LINEおよび当社が使う配信システムには、送っていただいた内容が記録されます。
