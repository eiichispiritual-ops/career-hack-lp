求人票で最初に見るところ4選

次に、求人を見るときの道具です。これだけ知っていれば、だいぶ避けられます。

  1. 「年間休日120日以上」の以上を見る

    120日はだいたい土日祝が休みの計算です。「120日以上」ではなく「110日」なら、月1回は土曜出勤がある計算になります。数字そのものより、何日からの話なのかを見ます。

  2. 「みなし残業」は、何時間分かを見る

    固定残業代・みなし残業と書いてある場合、何時間分が含まれているかが必ず書いてあります。そこが長いと、その時間までは働く前提の設計です。

  3. 「アットホームな職場」は情報ではない

    書いてあっても減点にはしません。ただ、給与・休日・残業のどれかが書かれていない求人票に限って、この言葉が入っています。書くことが無い欄を埋めた跡だと思って見てください。

  4. 離職率は、求人票の外で調べられる

    求人票に載っていなくても、会社の採用ページや口コミで人の入れ替わりの速さは見えてきます。どこを見るか、それさえ覚えておけば自分で確かめられる。

ここまでを自分で確かめたあとに残るのが、求人票に書いていないほうです。

求人票は、書いてあることを読むだけなら10分。

時間がかかるのは、書いていないことを確かめるほうです。
