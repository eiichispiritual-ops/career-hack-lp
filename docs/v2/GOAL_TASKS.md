## 画像ルール
- 各画像 v2/img/prompts/NN_name.json を先に書く → そのJSONからGPT imageで生成（キー待ち）。
- 色味は career-hack の配色（docs/v2/style.css の変数）に統一。文字は焼き込まない（HTMLで重ねる）。
