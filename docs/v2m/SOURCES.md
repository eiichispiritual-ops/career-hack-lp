- キャリアスタート「内定率86%」「内定獲得率90%」：2026-11-05付の公式記事（内定率37.32%・定義付き）と大きく食い違う。使用しない。

- リクルートエージェント 20代後半エンジニア 年収400万円→550万円：公式事例だが、今回のカード差し替えで不使用。

## 注意（運用メモ）
- これらは各社が自社サービスについて公表した数値で、キャリアハック自身の実績ではない。社名を付けずに大きく表示すると、当サービス単独の実績と受け取られるおそれがある（景品表示法の優良誤認の観点）。公開前に、数値ごとの社名併記や脚注の具体化を検討すること。
- 各社の定義・集計期間は数値ごとに異なる（同じ「定着率」でも期間や対象が違う）。
- 特典（求人票の見方チェックリスト／辞めた理由の言い換えメモ／職務経歴書テンプレート）は仮の内容。実際に用意できるものに合わせて差し替えること。
- 競合アフィリエイトLPの文言は転載していない。
