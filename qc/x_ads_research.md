## 2. X広告リポジトリ（ads.twitter.com/ads-repository）の閲覧可否

- **【事実】ログインなしで閲覧できる。** ヘッドレスブラウザで表示すると、"Ads Repository / Search for an advertiser or use the filter options to create a report." と国選択（初期値 France）、期間、「Create report」ボタン、「Commercial Communications CSV」のダウンロードリンクが出る。
- **【事実】** 国の選択肢はEU加盟国だけで、EU DSA（デジタルサービス法）にもとづく透明性レポートになっている。日本向けの配信広告は検索対象に入っていない。
- 「Create report」はフォーム送信にあたるため実行していない。
- 結論: **日本の転職LP広告を特定する用途には使えない。** 今回のLPは「SNS広告の遷移先らしいもの」（LINE誘導・lmes 計測・SNS向けクリエイティブ）を検索で集めたもので、**X広告に出稿されているかどうかは未検証【推定】**。

## 4. 横断まとめ

- **【事実】** LINE誘導型（キャリデリ、メグル、CHOICE!、だれでも相談）のCTAはLINE緑系（#06C755 / #44B02E / #00B938）。高さは52〜60px（固定・FV内）で、ピル型（999px）が多い。CHOICE! だけが4pxの角丸四角。
- **【事実】** 立体感の出し方は「下方向のベタ影 `0 6px 0 濃い色`」（キャリデリ、メグル）が今風。古めのLPは `2px 2px 1px` のドロップシャドウ（CHOICE!）。
- **【事実】** フォント: 新しいLPは Zen Kaku Gothic New / Noto Sans JP の太字（800〜900）。女性向けの大手は明朝体や欧文セリフを装飾に混ぜる（ウーマンキャリア、type）。
- **【推定】** 女性向けはピンク系（#DE4983, #EE5B67）+ 淡ピンク地。20代汎用はグリーン（#10B981）か、オレンジ + ネイビーの強いコントラスト。
- **電話相談の言い方の傾向【事実】:** 「電話」を前に出すのは公的窓口（だれでも相談）とエージェントのFAQ（type、ウーマンキャリア）ぐらいで、広告系LPは「オンライン」「ビデオ通話/チャット」「スマホだけで完結」「LINEで完結」と言い換えることが多い。メグルは「LINEか電話で相談日を決めます」と、日程調整の手段として電話を出している。
- **【推定】** 電話への抵抗感をやわらげる型は3つ: 所要時間の明示（30分・1回15分）/「まとまってないままでOK」/ 手段を選べる表現（電話・オンライン・来社のいずれか）。
